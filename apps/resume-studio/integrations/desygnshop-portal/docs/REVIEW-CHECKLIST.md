# Review this version

## Visual direction

Open `Design-Preview.html` and use its review bar. Look at AI Studio first, then the main website and launch packages. The storefront uses warm paper, evergreen, and coral, with matching artwork and typography. Illustrations are original concept compositions rather than customer products.

## Working local account journey

1. Start the local server and create a test account.
2. In AI Studio, choose a starting point, describe the vision, and give the project a name.
3. Edit its headline, description, services, contact email, and color. Save to update the starter preview.
4. Switch desktop/mobile preview size.
5. Make another edit. Open version history and restore the previous direction.
6. Download the website HTML and open it separately.
7. In My Workspace → My Brand, save brand details. Return to the editor and apply the brand, then save.
8. Build a launch package, choose quantities, and save its brief. Download the brief and revise a copy.
9. Review My Plan, Orders, and Billing. Drafts are separate from purchases; there should be no payment records.
10. Sign out, then sign back in. Confirm the records remain.
11. From the project editor, choose the launch-package link. Confirm its name, color, and direction appear in the package builder. Save the draft, then edit the original project and verify the draft retains the direction saved with it.
12. Open Account Settings. Update the name, export the workspace, and change the password. A second session for the same account should be signed out.
13. Using a disposable test account, open deletion review, enter the current password, and type DELETE. Confirm that account is removed while a different account remains intact.
